1. N6参考手册中无法检索到`RNG_S2/1`的名称，无法确认具体功能。

2. U5的RNG与N6一致，但IOMUX中没提及RNG，因此可以推断N6 IOMUX中的`RNG_S2/1`非必要

3. 参考手册中RNG模块的输入输出端口均不含熵源相关内容，因此可以排除数据手册中`RNG_S2`属于外部熵源的可能。
4. PCD100 TrustEngine的TRNG子模块在总线和时钟之外没有独立的端口信号需要连接。

| 信号名称      | 信号类型 | 描述                                                         |
| ------------- | -------- | ------------------------------------------------------------ |
| rng_it        | 数字输出 | RNG全局中断请求                                              |
| rng_hclk      | 数字输入 | AHB时钟                                                      |
| rng_clk       | 数字输入 | RNG专用时钟，与rng_hclk异步                                  |
| rng_itamp_out | 数字输出 | RNG内部篡改事件信号，发送至TAMP（异或方式），当发生意外硬件故障时触发。该信号触发后，RNG将停止提供随机样本，需要复位并重新初始化后才能再次使用。 |
